# FinSight Wealth Platform

## Overview

FinSight Wealth Platform is an AI-powered portfolio optimization system developed as part of the Cynaris AI/ML Internship.

The application helps investors build an optimized investment portfolio based on their:

- Risk Profile
- Investment Amount

The system uses Modern Portfolio Theory (MPT) to recommend an optimal asset allocation while balancing expected return and investment risk.

---

## Objectives

- Build an optimized investment portfolio.
- Calculate expected portfolio return.
- Calculate portfolio risk (volatility).
- Compute Sharpe Ratio for performance evaluation.
- Visualize portfolio allocation and risk-return trade-offs.
- Develop a clean, modular, and documented Python project.
